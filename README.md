# The Thurman Place

A family legacy site for the thirty-three acres outside Magee, Mississippi: the catfish pond, the house going up, and the plan Eldridge Lee Thurman drew for it.

Live site: https://xtraordinarydev.github.io/Thurman-Estate/

- `docs/` is the website. GitHub Pages serves it from this folder.
- `docs/index.html` is the story page, `docs/gallery.html` is every photo and clip.
- `Assets/` holds the original camera files and is not committed (see `.gitignore`).
